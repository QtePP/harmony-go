# RFCs

Protocol, plugin-contract and platform-constraint changes need an RFC before
implementation. Everyday changes do not.

## Process

1. Copy `0000-template.md` to `NNNN-short-title.md` (next number).
2. Open a PR with the RFC only (no implementation yet).
3. Comment window: at least 7 days.
4. The BDFL decides after the window. Accepted RFCs update `AGENTS.md` and the
   affected docs in the same commit as the implementation.
5. Rejected RFCs stay in the repository with a short decision note.
