# 本机窄意图 gate（不调用大模型）

> 状态：**真机已验成**（2026-11-23 22:17，CMM-AL10）。发 `你是谁` 立即出现本机回复和
> `本机规则 · 未调用云端模型` 标记；`dsh-home/sessions` 近 5 分钟新增 `.zstd` 为 0。

## 1. 它解决什么

问候、自我介绍、感谢、告别这几类消息**不需要云端模型**。在 `Index.dispatchSend` 的最前面做一次
**精确匹配**，命中就直接写入用户消息 + 本机回复，然后 return：

- 不打开 dsh session；
- 不发 `session/prompt`；
- 不产生 token；
- 不经过 Pyodide / pybot（pybot 冷启 25s，比云端还慢，不适合问候）。

## 2. 规则

精确匹配，先 trim、去掉首尾标点和空白、转小写；**不做子串匹配**：

| intent | 例子 | 回复 |
|---|---|---|
| greeting | `你好` / `hello!` / `在吗？` / `早上好。` | `你好，我在。要处理什么？` |
| identity | `你是谁` / `你叫什么` / `介绍一下你自己` | `我是 HarmonyGo，一个跑在鸿蒙设备上的 dsh 外壳；这条回复由本机规则直接给出，没有调用云端模型。` |
| thanks | `谢谢` / `thanks` | `不客气。` |
| bye | `再见` / `bye` | `再见。` |
| help | `你能做什么` / `帮助` / `help` | 能力摘要（对话/文件/Office/联网/Python 实验） |
| time | `现在几点` / `现在时间` | `现在是 22:31（2026-11-23 周一）。` |
| date | `今天几号` / `今天星期几` | `今天是 2026-11-23，周一。` |
| math | `1+1` / `2 + 3 * 4` / `算一下 10/4` | `1+1 = 2` / `2+3*4 = 14` / `10/4 = 2.5`（递归下降求值，不用 `eval`） |

**一个语气词收尾**（2026-11-24 加）：整句 = 白名单某项 + **至多一个** `啊/呀/呢/吧/哦/哇/嘛/啦`
时，也算命中同一意图——`你好啊` / `您好呀` / `谢谢啊` / `在吗呢` 都落到原来的意图上，
`算一下 3+4啊` 也会落到 math；不在白名单的句子（`天啊`、`早点睡吧`）仍然不命中。规则只剥一层、只剥句尾；`你好啊啊`、`谢谢你啊`、`好的吧`、
`天啊`、`早点睡吧` 一律不命中（`谢谢你` 本身不在 thanks 列表里）。加这条是因为实测常见的
`你好啊` 每次都在白名单外，等于给一句问候也付一次模型调用；扩成模糊匹配会吞掉任务，
所以宽严边界钉在「一个语气词、句尾、白名单内」三条上。

刻意不匹配：

- `你好啊，帮我写一个周报` —— 任务型（语气词后面还有内容），必须进 agent；
- `你是谁开发的？` —— 不是纯身份问题；
- 带附件（图片）的消息 —— 永远走真实 agent。

本地回复的 `note` 标成 **`本机规则`**，用户能看出这条没有走模型。

## 3. 边界

- 本机回复只写本地 `SessionStore`，**不在 dsh 服务端历史里**；下一轮云端模型看不到这句问候。
  对问候可接受，对需要上下文的对话不适用。
- ACP 会话若已 active，本机回复也不会进服务端上下文；同理。
- 规则是硬编码的，新增意图要改 `LocalGate.ets` 并补测试；不要用模糊分数，否则“为什么这条被吞了”无法审计。
- 它**不是 pybot**，也不是决策器：只覆盖四类窄意图；pybot 仍用于 `pybot_reply` 工具。

## 4. 规则缓存（反馈回路）

`LocalGateCache` 把每次消息的**归一化输入**和结果记到 `<filesDir>/local-gate-cache.json`：

- `hits` / `misses` 总数；
- 每条输入的次数、最后时间、命中的 intent、是否本机处理；
- 最多 200 条，超出按“次数少、时间旧”淘汰；输入截断 200 字符。

设置 → 诊断 → `--- local gate ---` 会显示 `hits N / misses M` 和 **未命中的前 5 条**
（例如 `3× 帮我总结这份文件`）。这些是**候选规则**，不是自动规则：

- 不会把模型回答自动缓存后回放——同一句话可能指向已变化的文件或上下文；
- 稳定后由人 review，把确认为固定话术的输入加进 `LocalGate.ets` 并补测试；
- 数据只在本机沙箱，明文保存；不含附件内容。

- `LocalUnit` 8 组用例：中英问候、身份/感谢/告别、帮助、时间/日期、四则运算与优先级、任务型不吞、空输入。
- 覆盖 16.9%（2026-11-23）。
- 真机：发 `你是谁` / `1+1`，立即出现带 `本机规则 · 未调用云端模型` 的回复；`1+1 = 2` 已在界面确认。
- 注意：设备被并行会话占用时，`sessions` 目录会因其他会话增长，不能拿文件大小当本 gate 的判据；应以界面 `本机规则` 标记和本地消息是否进入 dsh 日志为准。
